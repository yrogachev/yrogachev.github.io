Personal desktop application

InternshipAgent

A personal organizer for internship opportunities, application documents, and application updates.

InternshipAgent is a single-user tool for its owner's own job search. It runs on the owner's computer, organizes job opportunities, prepares application documents using approved background information, and maintains an application tracker.

How it uses Google services

  • Gmail reading: searches for job alerts and application-related messages, reads matching messages, and identifies updates such as interview requests and application outcomes. The requested read-only permission permits mailbox access; the application limits its searches to job-related terms.
  • Gmail sending: sends the owner a daily summary of their job-search activity. The current Gmail integration sends these reports only to the owner's own account.
  • Google Drive and Sheets: creates and updates the application's tracker and archives application documents in the owner's Drive. Access uses the file-specific drive.file permission for files created by or explicitly opened with the application.

Google access begins only after the owner authorizes the desktop application. This public website provides app information; it does not collect Google passwords or provide public registration.
