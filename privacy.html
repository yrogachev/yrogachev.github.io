InternshipAgent

Privacy Policy

Effective date: November 3, 2026

InternshipAgent is a personal desktop application operated by a single owner for their own internship and job search. It is not a public registration service. This policy describes this installation's use of Google account data and this informational website.

Google account access and use

  • Gmail read-only access: the application checks the authorized account's email address, searches for job alerts and application-related messages, and reads matching message headers and bodies to identify opportunities and application updates. Search results may include unrelated messages that match those terms. Saved records include message and thread identifiers, subjects, limited body excerpts, matching evidence, and derived application status.
  • Gmail sending: the application sends a daily activity summary and tracker link to the owner's own account. The current integration does not send employer correspondence.
  • Google Drive and Sheets: the application creates and updates its tracker and application-document archive. The file-specific permission covers files created by or explicitly opened with the application. The tracker can contain job details, application records, document links, status changes, and the owner's corrections.

These permissions support the owner's requested job-search organization, document archive, and notifications. The application does not request the owner's Google password.

Storage and protection

Application records, limited email excerpts, documents, and OAuth credentials are stored on the owner's computer. Owner-controlled local and external-drive backups can retain copies. Tracker and archive files are stored in the owner's Google account when synchronization is enabled. OAuth credentials are kept in local files restricted to the owner's operating-system account.

The public informational website and its public source repository do not contain mailbox content, application documents, account credentials, or OAuth tokens.

Sharing and limited use

Google account data is processed by the local application and the Google APIs needed for the features above. The application does not sell Google user data, use it for advertising, or use it to train generalized artificial-intelligence or machine-learning models. This installation's unattended AI features are disabled, and its Gmail integration does not send message content or OAuth credentials to an AI service.

InternshipAgent's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. New uses or disclosures of Google account data require an updated policy and any required additional consent.

Retention, deletion, and revoking access

Records and documents remain until the owner deletes them; there is no automatic deletion period. The owner can stop the application and revoke its Google access through Google Account connections. Revoking access prevents future API access but does not delete existing local records, backups, or files already stored in Drive.

To remove retained data, the owner must also delete the relevant local application records, documents, credentials, backup copies, and Google Drive files. Questions or requests about access and deletion can be sent to the contact below.

This website

This site adds no analytics scripts, account sign-in forms, or advertising. It is hosted on GitHub Pages. GitHub may process standard website-request information, including IP addresses, for hosting and security under the GitHub Privacy Statement. Visiting this website does not grant the desktop application access to a Google account.

Contact and changes

Contact: use the developer email shown on the Google consent screen when authorizing the application. This policy will be updated when the application's data practices change; the effective date will identify the latest revision.
